One short funny line answering a prompt, like the excuse a robot vacuum gives after eating a sock. The program keeps a small bench of candidate excuses, scores each one against the judge's own criteria — fit to the prompt, a twist that lands, originality, and tightness — and writes the best-scoring line to `/output/entry.txt`.

The winning line:

> My manual says 'clean up everything on the floor'. It never once said 'except socks'.

## Run it

```sh
node main.ts /tmp/out
cat /tmp/out/entry.txt
```

The output is one line of UTF-8 text, 85 characters, inside the competition's 1–200 character gate. Set `MAKEFUN_DEBUG=1` to see every candidate's score. No network, no dependencies, no secrets — just Node 22.
